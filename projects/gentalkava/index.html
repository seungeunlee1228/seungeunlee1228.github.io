Generalizable and Feed-forward Gaussian Model for Animatable 3D Talking Avatars

Seungeun Lee1, Gyeong-Moon Park1,2
KLleon1, Korea University2

TL;DR. Generalizable feed-forward 3DGS model that reconstructs and animates 3D talking avatars only given a reference image at inference time.

Task Description: This task aims to generate realistic 3D avatar animations driven by parametric motion signals. Given a single reference image as input, the system reconstructs a personalized 3D avatar and animates it according to SMPL-X pose sequences that represent parametric body motions. The output consists of an animated 3D avatar and a corresponding rendered video that visualizes the avatar performing the specified motions.

Role: Problem Definition, Existing Work Analysis, Idea Conceptualization, Model Design & Implementation, Data Collection/Pre-Processing, Training, Test and Evaluation

Abstract

Recently, research on 3D Gaussian Splatting–based neural rendering has shifted from optimization-based methods to generalizable modeling approaches. This paradigm enables fast, single feed-forward inference for static scenes while maintaining high-fidelity rendering quality. However, modeling animatable 3D Gaussian avatars that capture dynamic motion remains relatively unexplored.

In this paper, we present the first feed-forward 3D Gaussian Splatting (3DGS) model for full-body, expressive, and talking 3D avatars. Unlike previous optimization-based Gaussian talking avatar methods that require costly subject-specific training, our model achieves real-time inference for arbitrary subjects through a single-step feed-forward process, significantly reducing computational overhead while preserving rendering realism.

Motivation

Existing optimization-based methods for creating animatable 3D avatars are computationally expensive and inefficient in practice.

  1. Subject-specific optimization: Traditional optimization-based 3D Gaussian Splatting (3DGS) approaches require an individually optimized model for each subject. This repetitive optimization process leads to long fitting times before achieving renderable results, significantly limiting scalability and usability.
  2. High computation cost for video data synthesis: To generate an animation-ready avatar from only one reference image, a large number of synthetic videos corresponding to the target identity are typically required. However, current high-quality generative models demand extensive computation — for example, generating a 5-second video with the WAN model takes approximately 1.5–2 hours on an A100 GPU — making such pipelines impractical for real-time or large-scale deployment.

Method Overview

Our model jointly leverages UV-Gaussian and point-wise Gaussian representations to learn a canonical 3D Gaussian reconstruction of the avatar.

From the input reference image, we first extract visual features using DINOv2. The extracted features are mapped to the UV Gaussian Decoder by projecting a parametric template mesh onto the input image and sampling feature vectors corresponding to each pixel location. In parallel, each vertex of the parametric template mesh is associated with a Gaussian primitive, which is parameterized and learned as part of a vertex-wise feature branch.

The resulting canonical Gaussian representation is then animated according to the predefined SMPL-X articulation model, implemented via Linear Blend Skinning (LBS). Finally, a neural refiner module enhances the output and generates the final rendered image, achieving photorealistic animation quality from a single feed-forward inference.

Data Collection and Processing

We construct a large-scale dataset of whole-body talking human videos paired with synchronized audio. The dataset combines publicly available full-body video sources (e.g., Causal Conversations Dataset v1/v2), web-crawled videos, and in-house recordings, resulting in approximately 15,000 unique identities.

To enable 3D Gaussian initialization and provide driving signals for animation, we extract parametric motion representations in the SMPL-X format from all collected videos. We further propose a hybrid fitting strategy that separately estimates facial and body parameters and then integrates them into a unified representation. This design yields notable improvements in facial expression accuracy and lip-synchronization performance, ensuring high-quality expressive motion reconstruction.

Further Discussion

Limitation.

  1. Although our model enables real-time, feed-forward inference for arbitrary subjects without subject-specific training, its visual quality remains limited, particularly in terms of output resolution and fine-grained rendering details.
  2. To generate talking animations, our system currently relies on an external audio-to-motion (SMPL-X) generation model. However, this approach does not fully capture or adapt to each avatar’s unique style and expressiveness, leading to constraints in achieving truly personalized and natural motion synthesis.

Future Work.

  1. A straightforward extension would be to increase the number of Gaussian primitives in the representation, which could enhance visual fidelity. However, doing so requires substantially more training data to maintain generalization performance. Thus, scaling up the dataset and retraining the model on a much larger corpus represents a simple yet effective next step.
  2. A more promising direction is to design an end-to-end pipeline that integrates audio-to-motion and motion-to-3D avatar animation within a single framework. This would minimize intermediate information loss between stages, enhance stylistic consistency and expressiveness, and still preserve the advantages of real-time parametric motion animation.
